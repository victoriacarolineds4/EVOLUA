# EVOLUA

## Identidade

O EVOLUA é uma plataforma de diagnóstico e desenvolvimento humano criada pela Neon Conecta.

Nosso objetivo não é entregar um teste comportamental.

Nosso objetivo é gerar clareza para empresários desenvolverem pessoas.

Lema oficial:

"Toda pessoa pode evoluir quando recebe a direção certa."

---

## Filosofia

Sempre priorizar:

- Simplicidade
- Clareza
- Elegância
- Performance
- Escalabilidade

Nunca criar funcionalidades desnecessárias.

Sempre pensar como um produto SaaS Premium.
